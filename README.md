# Sable BioClinic 

Patient Portal Intake System
A client-side web application built for a healthcare patient intake workflow. Developed as part of MIS 3371

Features
- Dynamic form validation for patient data including username, email, password, SSN, phone, and address fields
- Real-time password strength feedback and confirmation matching
- Interactive pain level slider with live output
- Form review table that displays entered data before submission
- Sensitive fields (password, SSN) excluded from review for privacy
